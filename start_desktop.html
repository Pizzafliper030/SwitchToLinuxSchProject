The Linux Desktop

Unlike Windows or macOS, Linux doesn't force you into one single desktop look. What you're seeing here is called a desktop environment — GNOME, KDE Plasma, XFCE, and others are all different, swappable desktops you can pick between.

Most beginner-friendly distros pick one for you by default and it works great out of the box. But if you ever want something that looks or behaves completely differently, you can usually just install another one alongside it.
