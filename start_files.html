Files and Folders

Your file manager (Nautilus, Dolphin, Thunar, depending on your desktop) works like File Explorer — browse, drag, drop, rename, the usual.

The underlying filesystem is actually simpler once it clicks: no C:\ drive letters, no separate drive letters for every device. Everything hangs off one single root folder.
